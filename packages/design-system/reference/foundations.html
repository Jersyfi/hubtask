Guiding idea

Depth is
hierarchy.

Hubtask has five levels. Instead of explaining them with indentation and guide lines, the design system makes the z-axis carry that information: the deeper an item sits in the structure, the deeper it sits on the screen.

That gives the three-dimensional effect a job. It is not surface polish, it is meaning — and precisely because of that it stays sparse. Where there is nothing to distinguish, there is no depth.

Levels 04 and 05 are recessed, not raised. A work package belongs inside its task — the eye reads “within”, not “above”. Only overlays (dialog, popover, command palette) genuinely sit on top, and they are the only thing that blurs.

01 — Colour

Two colours, two jobs

Dark blue and dark red do different work. The blue is the working colour: buttons, links, focus, selection — everything you look at all day stays calm. The bordeaux is the signature colour: brand, website, the celebration when a task is completed, the sheen on glass edges. It deliberately carries no system meaning.

Errors and destructive actions therefore get their own, warmer red. Otherwise the brand would shout “careful” every time it only means to say “Hubtask”.

Label tokens

The domain model stores a colorToken on Label and cover, not a hex value, so that theming works. These ten tokens are the complete set the API is allowed to know. Both modes are defined here; the backend stays colour-blind.

All ten reach at least 4.5:1 as text on their own background, in both modes. Colour never stands alone: every label also carries its name, every status also carries an icon.

02 — Typography

One superfamily

IBM Plex, in three cuts: Condensed for headlines, Sans for the interface, Mono for IDs, timestamps, keyboard shortcuts and code in the documentation.

The reason is not taste, it is the requirements list. Plex covers Arabic, Hebrew, Devanagari, Thai and CJK — otherwise “multilingual without backend changes” fails at the typeface. It is licensed under the OFL, so it ships with a self-hosted instance without anyone having to call Google Fonts. And one family means one font pipeline for website, desktop, mobile and docs instead of four.

03 — Depth & glass

Four levels, no more

elevation.flat

Navigation, sidebar, headers. Hairline only, no shadow.

elevation.raised

Tasks, cards, list rows. Soft shadow, clearly detached.

elevation.nested

Work packages, activities, buckets. Recessed rather than raised.

elevation.overlay

Dialog, popover, command palette. Glass, blur, two-tone edge sheen.

The rules that keep it restrained

R1

Only elevation.overlay may blur. Content is never placed behind glass.

R2

At most one glass surface visible at a time. Two stacked glass surfaces are a design error, not an effect.

R3

The edge sheen runs blue to bordeaux, always at 135°, always below 45 % opacity. It marks the edge, it does not glow.

R4

Shadows are never saturated — they are desaturated navy. Coloured shadows make any surface look cheap.

R5

Where backdrop-filter is unavailable (older webviews, Windows compositing failures), glass falls back to an opaque surface. No layout shifts.

04 — Motion

One moment worth celebrating

A to-do app has exactly one gesture that has to feel good: completing something. There — and only there — the system makes an effort. The check springs into place, a sweep in the brand colours runs once across the row, a few sparks fly off, the title strikes through.

Everything else moves in under 200 ms and only in opacity and transform. No layout is ever animated. Try it:

Finalise quote for the Nordstrasse site 2 days overdueJW
Check quantity take-off tomorrow
Request subcontractor quotes Fri, 14:00

Durations & curves

duration.fast · 120ms
duration.base · 180ms
duration.slow · 260ms
duration.deliberate · 400ms

Under prefers-reduced-motion the celebration reduces to a colour change and a line in the status region. The sparks are dropped entirely — they are a bonus, never information.

05 — Components

Building blocks

Actions

A button says what happens: “Create task”, not “Submit”. The wording stays consistent across the whole flow — what reads “Publish” reports “Published” afterwards.

Input

States from the domain

Overdue Due soon Completed Archived Offline · 3 changes Degraded

The last two exist because Hubtask keeps working offline and degrades in a controlled way when a dependency is missing, rather than crashing. The interface has to be able to show both without looking like an error.

Level path

Trade business/ Client projects/ Nordstrasse site/ Shell construction/ Sign off reinforcement

Five levels fit on no phone in a single line. From the medium breakpoint down, the path collapses to Hub / … / Parent / Current; the “…” opens the rest as a popover.
