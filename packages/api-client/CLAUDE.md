# packages/api-client — generated, and nothing else

Everything under `dist/` comes from `api/openapi.yaml` by way of `make api-client`. The
specification is the source and the code is the result
([ADR-0004](../../docs/adr/ADR-0004-api-first-openapi.md)).

## What must not happen here

* **No hand-written type.** An interface, a hand-built type alias or a runtime export under `src/`
  fails `pnpm lint`. If the type you need is missing, it is missing from the contract: change
  `api/openapi.yaml`, run `make generate` **and** `make api-client`, and put both halves in one
  pull request.
* **No fetch layer, hand-written or generated.** The TypeScript client for third parties is
  `sdk/typescript` (P-03, ADR-0059 §6): Apache-2.0, generated by `tools/sdkgen` on
  `make generate`, and typed against its *own* generation of the document rather than against
  this package. The first-party apps' fetch layer is the sync engine's `Transport` port
  ([ADR-0033](../../docs/adr/ADR-0033-shared-client-architecture.md)); a component that imported
  the SDK's class would be a component that could reach past that seam, and the workspace map
  lint refuses the edge.
* **No committed output under `dist/`.** It is ignored: reproducible from the specification and
  the lockfile, and a committed copy would be a second description of the contract to keep in
  step. Beside the types, `dist/` carries the document itself — `openapi.json`, copied from the
  `api/openapi.json` that `make generate` writes, and `events.json`, the CloudEvents schemas
  gathered by type — for the website's reference (P-01) and, from `0.9.0`, the generators.
* **No dependency on anything under `apps/`.** A package that knows about an application is not a
  shared package.

## Why the constraint is this strict

[ADR-0027](../../docs/adr/ADR-0027-monorepo-structure.md) deferred a decision to before `1.0.0`:
whether the generated SDKs move to a separately licensed repository, because a client library
under BSL 1.1 is one nobody may use in commercial production and therefore nobody builds on.
Keeping this package free of hand-written code is what keeps that extraction a move rather than a
rewrite. The licence half is decided — the SDKs are Apache-2.0 under `sdk/`, this package is
first-party `BUSL-1.1` throughout ([ADR-0059](../../docs/adr/ADR-0059-licensing-phases-and-licensing-start.md)
§6) — and the header test in `test/architecture` holds the boundary: an Apache-2.0 header in this
package fails it.

## How to check a change

```bash
make api-client
pnpm --filter @hubtask/api-client lint
pnpm --filter @hubtask/api-client typecheck
pnpm -r typecheck        # the consumers still agree with the regenerated contract
```

Nothing here is importable from Go, and no `.go` file belongs in this directory.
