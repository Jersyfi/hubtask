# PK-03 — sign in with a passkey

**When:** 2026-10-17 · **Branch:** `claude/pk-03-sign-in-with-a-passkey` at `464993bd1`
**Kind:** using ([README](./README.md), "How to walk"). The server was built from the branch with the
web app's bundle embedded and run against a fresh PostgreSQL 16 (pgvector) migrated to 0169, single
mode, `HUBTASK_BASE_URL=http://localhost:18490`; the installation was set up with its setup code for a
throwaway owner. Playwright drove Chromium, light theme, English, 1280 × 900, with Chromium's virtual
authenticator (a platform authenticator with user verification) standing in for the device. Real
challenge, real verifier, real transactions - nothing stubbed.

**Use case checks it shows:** UC-ID-21 checks 1, 2, 7 and 8 (the way in), UC-ID-22 check 1 (the last
use). Checks 3, 4 and 9 are proven by the service tests, the integration tests and
`apps/webapp/e2e/passkeysignin.test.mjs` (the keyboard and the status region).

**What was not walked:** a real platform passkey (Touch ID, Windows Hello) - the field's offer in
particular is the browser's own interface, which the virtual authenticator answers without drawing.
Asked of the owner on the pull request.
