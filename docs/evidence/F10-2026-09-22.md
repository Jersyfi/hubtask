**2026-09-22, the F9 walk's server (the compose stack, image `f9-walk`, the `f9-walk` workspace on
its kept volume) under the client built from `main` at `bfe0cf71`, served over a local proxy so

## 2. What the server actually refuses

Driven against the real server, with the walking account's own session:

| Write | Answer |
|---|---|
| `PATCH /items/<activity>` with `notes` | `422 capability_not_supported` |
| `PUT /items/<activity>/labels/<id>` | `422 capability_not_supported` |
| `PATCH /items/<activity>` with `cover` | `422` |
| `PATCH /items/<work package>` with `cover` | `422` |
| `PUT /items/<work package>/recurrence` | `422` |
| `GET /items/<activity>/comments`, `/attachments`, `/reminders` | `200`, all empty |

And the manifest's three profiles, which are `domain-model.md` §2 exactly: a task fourteen
capabilities, a work package eleven (no `BUCKET`, no `COVER`, no `RECURRENCE`), an activity five
(`COMPLETION`, `DUE_DATE`, `REMINDER`, `ASSIGNMENT`, `HISTORY`). The e2e fixture said `ASSIGNEE`
for `ASSIGNMENT` and gave a work package two of the fourteen — a fake that agreed with no
installation, and the reason the column's silence went unnoticed. It now carries the three
profiles as answered.

The details column, after the fix, on the real server:

```
task         assignee, due, labels, reminders, recurrence, language, cover, attachments
workpackage  assignee, due, labels, reminders, language, attachments
activity     assignee, due, reminders, language
```

## 4. What is not a defect

* **Administration is not reachable without the rights.** The row appears only where `GET /quotas`
  is not refused — `STRUCTURE`, or the auditor's `READ_CONFIGURATION` — which is the area's
  condition exactly, and the server refuses every screen under it regardless. Read from
  `navigation.ts` and `AppFrame`; ADR-0061 decision 1, unchanged by ADR-0062.
* **An archived entry is a state, not a hiding place** — it stays in its list with its badge,
  which is I-W4's shape and is right. **An archived container is neither.** `containers.svelte.ts`
  never passes `include_archived` and the route defaults it to `false`, so an archived hub or
  collection leaves the navigation and nothing shows it again. Driven on the server: archiving
  *Garden* left `Kitchen` in the listing and `Kitchen, Garden (archived)` with the parameter, and
  the sidebar afterwards read *Workspace, Search, Jumble, House, Trash*; unarchiving it needed the
  API. Filed as issue 933, and it is what F10-03 has to make untrue.
* **The board's drag lands.** Driven with a pointer from the grip of *Order the tiles…* across to
  *Doing*, the card changed column and the write carried it. The gesture is sound; the affordance
  and the feedback are what fail.
* **`503` on `/stream` during the walk** is the walk's own: many contexts under one credential meet
  the per-credential cap, as [`F9-2026-09-22.md`](./F9-2026-09-22.md) already recorded.

## 5. What is owed

Nothing of milestone F10 is built. [ADR-0062](../adr/ADR-0062-navigation-and-the-working-surface.md)

in it, are the owner's before a task of [`milestone-F10.md`](../backlog/milestone-F10.md) starts.
