# UX-02 — every script in its own face

**When:** 2026-10-21 · **Commit:** `9e830852d` on `ux-02-script-faces`
**Kind:** looking ([README](./README.md), "How to walk"): `pnpm --filter @hubtask/webapp build`,
`apps/webapp/e2e/preview.mjs` over the shared fixture, and a temporary Playwright probe (Chromium)
that answered `/meta/capabilities` with `ar`, `hi`, `bn`, `zh-Hans` and `ru` among
`supported_locales`, the account's locale set to each in turn, and the collection and its entries
retitled in that language's script. For the build only, `locales/` held walk-only catalogues for the
five tags with four navigation keys set to the language's own name (from `Intl.DisplayNames`) —
no translation, never committed (`i18n-l10n.md` §3). The probe and the catalogues were deleted and
the bundle rebuilt afterwards. Each language at 375, 768 and 1280 px wide, light and dark: 30 pages.

**Use case checks it shows:** UC-ID-23 checks 1, 2, 3 and 4 (the tests named in the pull request
prove them; this shows them). The screenshots break the README's "screenshots are in English" on
purpose: the letters are what is shown. The interface around them is the source language, since no
catalogue for these languages exists.

The screenshots are in [`UX-02-2026-10-21/`](./UX-02-2026-10-21/); what the probe read on each page
— `lang`, `dir`, `data-script`, the theme, the heading's first family, the faces loaded and every
font request — is in [`walk.json`](./UX-02-2026-10-21/walk.json).
