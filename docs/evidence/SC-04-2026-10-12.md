## The gates that run the same against the image

`make gate-compose` and `make gate-e2e` against the image built from this branch, both green:
`compose-smoke.sh` sets up both stacks through the printed code and writes its reminder fixture
through the owner's API calls; `hubctl-e2e.sh` sets up its workspace the same way and mints every
token it needs through the API, `admin:tenants` behind a step-up. The first `gate-compose` run
found that a single-mode workspace was seeded with the installation's own host, which `localhost`
cannot be — fixed in the pull request (`fix(admin): a single-mode workspace is seeded without a
host`).
