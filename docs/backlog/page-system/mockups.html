One page system

Every screen is one of seven page kinds, built from compositions the design system ships. Switch the width above, or narrow the window: every scene follows the five widths.

Levels: two at most

Separate by space, a heading and a hairline first. A container only where an object stands on its own — never a container in a container. A shadow only for what moves or lies over.

0 Canvas
The page. Head, strip, filter bar, headings sit here directly.
1 Region
One per thing the page is about: a table, a settings section's rows, a block list. Hairline, no shadow. Never a region in a region.
1′ Item
Items to pick from (templates, hubs) directly on the canvas, never inside a region.
Sunken
A backdrop inside the canvas or a region: a group row, a board column, a flow diagram.
2 Raised
Only what moves, and at most one focal card per screen.
3 Overlay
Dialogs, sheets, menus. One at a time; Discard changes? is the only one over another.

Where a task opens — the ladder

Take the first rung that fits. Never a split between a list and a form.
