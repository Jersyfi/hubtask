## 3. Decisions

- [x] D1 The preset answers `personal_directories`, which is `PersonalDirectories` as the refusal
  reads it; `personal_issuer_paths` keeps its meaning — decided by: worker, F-1464 D1's reasoning (the
  screen reads the server's list, never a copy). Rejected: reading `personal_issuer_paths`, which
  would also refuse `common` typed as a directory, which the server saves (§ 1); a copy of the id in
  the web app.
- [x] D2 The form says it as the field's error while the mode is not `INVITED_ONLY`, and does not
  hold the save back. The server's refusal is the same sentence, and a form that blocked the
  button would need a second rule for when to release it — decided by: worker; the pattern F-1464
  D2 set for `provisioning_personal` (said where it is chosen, the save the server's). Rejected:
  removing the entry for the person (it changes a value they typed, unseen).
- [x] D3 No ADR — identity.md §10.4 holds the rule; §10.3, the paragraph that names `shared_issuer_paths`
  and `personal_issuer_paths` gains `personal_directories` in step 2.
