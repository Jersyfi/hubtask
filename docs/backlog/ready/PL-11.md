## 3. Decisions

- [x] D1 The link is a legal-area key (`legal.account_url`) at the installation and per plan, kept out
  of `LegalSettingNames()` - a second list names what the installation and plan levels carry - so the
  workspace's own policy and the anonymous sign-in rules never see it — decided by: worker; rejected:
  a new area (nine places for one key).
- [x] D2 It resolves installation → plan only: the installation's lock binds the plan, a plan's value
  replaces the installation's where open; a plan cannot lock it — decided by: multi-tenancy.md §4.2,
  identity.md §18.
- [x] D3 Its lock describes plans, not workspaces: `workspace_may: PLAN_REPLACE`, "Plans may set their
  own" / "Plans may not change it" — decided by: worker (UI wording in the approved preview's
  vocabulary).
- [x] D4 "Owners and administrators" is whoever holds `STRUCTURE` on the workspace itself, decided at
  both doors by the same function (`service.Held` over the account's workspace-level memberships, as
  `HeldOnWorkspace` reads them) — decided by: domain-model.md §3.2 (only OWNER and ADMIN hold it).
- [x] D5 The paused page is the notice a person of a paused workspace meets on the sign-in screen: the
  refusal after the person's complete proof carries the link for an owner or administrator, and a
  signed-in person whose request is refused as paused is signed out locally and shown the same notice
  - decided by: worker, because a suspended workspace answers no authenticated read; rejected: a
  public route answering the link (anybody could ask for any workspace's).
- [x] O1 The preview's paused page sits inside the app with "Daten exportieren"; no export door exists
  for a paused workspace's own people (the operator exports it) — decided by: owner, 2026-10-18,
  option A (asked through the session that runs this series, answered in the owner's conversation),
  a deviation from the approved preview: no export button and no sentence promising one; the notice
  after the person's complete proof at sign-in and when a signed-in person's request is refused as
  paused, worded "Dieser Arbeitsbereich ist pausiert. Deine Daten sind vollständig erhalten. Warum er
  pausiert ist und wie es weitergeht, weiß dein Anbieter.", with "Kontoseite deines Anbieters" for
  owners and administrators only.
- [x] D7 "At a reached limit" is a notice on *Limits* when a row's use has reached its non-zero limit,
  naming the limit and saying that nothing existing changes, with the link. The preview's "people"
  limit is PL-04's quota, not built yet; PL-03 (#1579) changes the same screen and goes first - this
  task's screen step is rebased onto it — decided by: the approved preview.
- [x] D8 A workspace pending deletion answers the link on the same terms: whom to ask is the same
  provider — decided by: worker, P-11.
- [x] D9 The OIDC sign-in's missing status check is fixed here, test first in its own commit, named
  in the pull request as a finding — decided by: AGENTS.md (a finding fixed on the branch).
