## 3. Decisions

- [x] D1 A language is named with `languageName(tag, reader)` wherever a tag was printed — decided by:
  worker; it is the profile's existing answer, so the three screens agree. Rejected: catalogue codes
  per language (a second list beside `Intl`).
- [x] D2 Attachment storage is printed with `formatBytes` on *Limits* and in the *Defaults* table;
  the *Defaults* input stays a number of bytes, its hint naming the size in words — decided by:
  worker; an input that takes "10 GB" would need a parser and a unit choice nobody asked for.
  `hubctl` prints an integral JSON number in plain digits (`strconv.FormatFloat(v, 'f', -1, 64)`),
  any other value as before.
- [x] D3 A locked rule's origin line is left out where its control already says the lock - decided
  by: worker; the control's reason is the one tied to it for a screen reader (`aria-describedby`).
  The existing e2e assertion that read the lock from the origin line now reads it from the rule
  and asserts it once.
- [x] D4 The overview's *Defaults* line counts what the *Defaults* screen counts, every area, as
  "settings" (new code `app.instance.digest_settings`, `digest_sign_in` removed), still with the
  locked count - decided by: worker. UC-INS-12's *Story* ("the sign-in defaults in one line") then
  reads one line for all defaults, which the *Story* (not owner-locked) does not forbid. Rejected: renaming the line to *Sign-in* (the button opens *Defaults*, whose own count
  would still differ).
- [x] D5 In single mode (`capabilities.isSingleTenant`) the overview omits the two counters, and the
  journal and *Limits* use single-mode sentences (`app.instance.journal_intro_single`,
  `app.quotas.intro_single`, `app.quotas.raising_single`) that name neither *installation* nor
  *operator* - decided by: worker, from deployments.md D1. The *Limits* sentence is worded for a
  reader who may not reach the installation's section (D3's volunteer, D4 single mode with a
  platform team): it names the section *Applies to every workspace you create* where it is in their
  administration, and otherwise says to ask whoever set Hubtask up. Multi mode is unchanged.
- [x] D7 Two words D1 meets stay, because changing them is the owner's: UC-INS-12 check 2 asks for
  "you are the operator because this installation has one workspace", and UC-INS-09 check 5 for "set
  by the installation" (`app.signin_settings.locked_installation`, `app.quotas.locked_installation`)
  — both against deployments.md:28. This fix does not touch them; the conflict is reported to the
  coordinator to put to the owner as a `decision` issue — decided by: worker (not to decide it).
- [x] D6 The phone drawer's cut row is not fixed here: it is `SideNav`'s ellipsis, and a design-system
  component is not changed as a side effect of other work (`packages/design-system/AGENTS.md`). The
  words are UC-INS-04's. Reported to the coordinator as a finding for a design-system task — decided
  by: worker.
