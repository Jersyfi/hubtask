- [x] D1 UC-WRK-01 check 6 / UC-WRK-22 check 4 ("not shown *Create hub*") and UC-ID-16 check 1
  ("may create a private hub for themselves whatever their role") are read together as two
  controls: *Create hub* makes a hub of the workspace's shape and needs `STRUCTURE`; *Create private

  workspace, where the workspace allows private hubs and holds more than one person (the condition

- [x] D3 For a reader without `STRUCTURE`, the dialog creates only a private hub: no *Private*
  switch, the hint said as a line, `private: true` sent — decided by: worker; a shared hub would
  be refused.
- [x] D4 No ADR: ADR-0073 §2 holds the rule; `api-guidelines.md`/the manifest's description gets the
  field.
