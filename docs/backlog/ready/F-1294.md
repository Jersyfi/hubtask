## 3. Decisions

- [x] D1 The refusal keeps its class (`ErrUnavailable`, 503) with its own detail
  `ai.budget_spent` and the parameter `renews_at` — decided by: issue #1294's proposal, the
  `ai.source_not_allowed` precedent (SC-11). `errors.Is(err, aiprovider.ErrUnavailable)` holds for
  it (`shared.Error.Is` compares the class, not the detail), so callers that only ask "unavailable?"
  degrade as before.
- [x] D2 A provider that refuses can say why: an optional port interface `ai.Refusing` with
  `Refusal() error`, and `ai.RefusalOf(provider)` answering it or `ErrUnavailable`. The four
  places that short-cut on capabilities ask it instead of naming `ai.unavailable` themselves —
  decided by: worker. Rejected: giving `exhausted` completion capability so the call reaches
  `Complete` (the manifest and the embedding pass would then think a model is there).
- [x] D3 The renewal is asked of the budget (`AiBudget.AiRenewal`), the next midnight of the
  workspace's day — decided by: worker; the guard owns the zone and the day.
- [x] D4 The web app formats any problem parameter named `*_at` as a moment in the reader's locale
  before the sentence renders — decided by: worker; `format.ts` refuses dates by design and
  `datetime.ts` is where moments are written.
- [x] D5 `infrastructure/ai.Refused` (`ai.source_not_allowed`) is not made `Refusing` here, though it
  has the same short-cut: a different use case's behaviour; reported as a finding.
- [x] D6 ai-first.md says "a refusal is always `ErrUnavailable` with `ai.unavailable`"; ADR-0049
  chose one refusal so callers need one handling. The class stays one (D1) and every caller's
  handling is unchanged; only the detail a person reads names the cause. That is a correction of the
  sentence, which `ai.source_not_allowed` already made untrue, not a deviation from the rule — decided
  by: worker, with UC-AI-07 check 3 (the owner's) as the requirement. ai-first.md, multi-tenancy.md
  §4's budget paragraph and api-guidelines.md are corrected in step 5; ADR-0049 is history and stays.
