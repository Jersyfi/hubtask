## 3. Decisions

- [x] D1 The refusal stays exactly the one refusal - `ErrUnavailable`, 503, detail `ai.unavailable` -
  and carries two new parameters, `reason = budget_spent` and `renews_at` (RFC 3339); the catalogue's
  `ai.unavailable` sentence becomes a `select` on `reason` — decided by: worker, after review.
  ai-first.md §2, ADR-0049, the port's own comment and `api/openapi.yaml` (the `AiTokensPerDay` and
  translation descriptions) all fix `ai.unavailable` as what a spent budget answers, and clients key on
  `detail_code`; a new detail code would be a deviation from a subject document's rule, which is the
  owner's. An additive parameter changes nothing a client or a caller relies on (`IsUnavailable`, the
  worker, the contract) and meets check 3. Rejected: a detail `ai.budget_spent` (the issue's
  proposal) — it would need the owner's decision first.
- [x] D2 A provider that refuses can say why: an optional port interface `ai.Refusing` with
  `Refusal() error`, and `ai.RefusalOf(provider)` answering it or `ErrUnavailable`. The four
  places that short-cut on capabilities ask it instead of naming `ai.unavailable` themselves —
  decided by: worker. Rejected: giving `exhausted` completion capability so the call reaches
  `Complete` (the manifest and the embedding pass would then think a model is there).
- [x] D3 The renewal is asked of the budget (`AiBudget.AiRenewal`), the next midnight of the
  workspace's day — decided by: worker; the guard owns the zone and the day.
- [x] D4 The web app formats any problem parameter named `*_at` as a moment in the reader's locale
  before the sentence renders — decided by: worker; `format.ts` refuses dates by design and
  `datetime.ts` is where moments are written. The moment is shown on the reader's clock, which is the
  workspace's midnight as an instant; it also fixes `containers.emergency_running`'s `{ends_at}`,
  which renders raw today (named in the pull request as found in passing).
- [x] D5 `infrastructure/ai.Refused` (`ai.source_not_allowed`) is not made `Refusing` here, though it
  has the same short-cut: a different use case's behaviour; reported as a finding.
