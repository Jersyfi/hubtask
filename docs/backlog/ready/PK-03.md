- [x] D1 `StartPasskeySignIn` (`POST /auth/sessions:passkey-options`, 200) and `CompletePasskeySignIn`

  `FindArrivalPendingByHash` gains `purpose = 'TERMS'`; the options call seeds the workspace's
  retention sweep so expired rows go. A MAC'd stateless challenge was rejected: single use needs a

  no cross-origin or top origin, no token binding), the RP ID hash, UP, BS only with BE, BE equal to

  not the current one is none; the user handle must be present and equal — decided by: §23.3,

- [x] D8 A UV assertion is the proof: no `TOTP` or `ENROLL`; the rule's own `PASSWORD_CHANGE`
