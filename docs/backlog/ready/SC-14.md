## 3. Decisions

- [x] D1 Okta and GitLab are **removed**, not replaced — decided by: the task text ("marks without a
  preset removed") and the code (§ 1: no preset exists for either). Apple and Slack go for the same
  reason. A provider configured as `GENERIC` with one of those names draws the letter tile, which
  is ADR-0069 §4's answer. No new third-party asset is added.
- [x] D2 The brand-mark rows live in the **template** `tools/licenses.md.tpl` as a static table
  under "Bundled assets", so `make licenses` regenerates them and the existing byte comparison
  keeps them — decided by: worker. A second file would be a second place for the same kind of
  entry; ADR-0069 §2 names `THIRD-PARTY-LICENSES.md`. Columns: mark (with its preset in code
  font), source (the owner's guideline page), what the guideline permits. No licence column: a
  trademark is not licensed to us, it is permitted for a use, and the row says which.
- [x] D3 The gate check is a script `scripts/check-brand-marks.sh` called first by `gate-licenses`
  — decided by: worker. It reads three places and refuses: a preset drawn in `ProviderMark.svelte`
  (`preset === 'X'`) with no row naming `` `X` ``; a row naming a preset that is not drawn; a
  drawn preset absent from `IdentityProviderKind` in `api/openapi.yaml`. On success it prints the
  marks it checked ("brand marks: GOOGLE, MICROSOFT - each drawn, listed and a preset"), which is
  "the licences gate names every mark". A script, not a Makefile block, so `gate-selftest` can
  show each refusal. Rejected: a Node lint beside `lint-no-literals.js` — the licences job installs
  no Node, and the obligation belongs to the licences file, not to the design system.
- [x] D4 The proof of check 4 is an engine test of the sign-in card (`signin.test.mjs`, a `GOOGLE`
  provider added to its `RULES`) — decided by: worker. It asserts that each brand button holds an
  inline `svg` with the published colours and no `href`/`src`, that the `GENERIC` one holds the
  tile with its initial, and that no request left the origin while the card was drawn. A unit test
  of the component would need a Svelte test harness the app does not have.
- [x] D5 `design-system.md` §12 and `ci-cd.md` (the `licences` row) say that the gate checks the
  marks — decided by: worker; a document stating the system wrongly is corrected in the same pull
  request. ADR-0069 itself is not edited (an accepted ADR does not change), and needs no errata
  row: the table in `docs/adr/README.md` maps a cited section that does not exist, and ADR-0069's
  sentence "checked by the gate that already keeps that file honest" becomes true with step 4.
- [x] D6 The published Google file cannot be pasted as it is: it carries two `style` attributes
  (`mask-type`, and the conic gradient on a `foreignObject` element), which `style-src 'self'`
  refuses — the G would lose its gradient silently — and fixed ids, which two Google buttons on one
  screen would share. The declarations move verbatim into the component's stylesheet as two
  classes, the ids take `$props.id()` as prefix, the button frame around the G is dropped (the
  button is ours, ADR-0069 §1) and the view is the G's own box `10 10 20 20`; every shape, blur and
  colour is the file's. Figma's `data-figma-*` metadata is left out (not drawn). — decided by:
  worker; the alternative, a CSP exception for the mark, is a change to the security gates and the
  owner's. A comparison of the rendered G with the published file at 3× showed no difference.
- [x] O1 **The Google and Microsoft marks are redraws** (§ 1), and ADR-0069 §2 says "reproduced as
  its owner publishes it … never simplified" — decided by: owner, 2026-10-12, #1292 (a) → written
  in `milestone-SC.md` Decision 13: each published file downloaded once into the worker's scratch
  space, its paths copied unchanged but for the viewBox scale, the file not committed, the row
  naming the exact file and the guideline.

## 4. Proof and steps

UC-ID-09 check 4 — "the provider's mark is shown in its published neutral form, never recoloured,
loaded from the bundle and not from the provider's servers":

- *Published form, never recoloured:* the engine test asserts the fills of each mark against the
  published colours, and step 6 (after O1) makes the geometry the published file's; the row names
  that file, so a reader can compare.
- *Neutral form:* the button is `Button tone="secondary"` (unchanged); the test asserts the mark sits
  in the secondary button and no brand colour is a surface (the button's computed background is the
  `bg.surface` token's value).
- *From the bundle:* the test records every request the page makes while the card is drawn and
  asserts none leaves the preview origin; the CSP in `presentation/webui/Handler.go` holds it at run
  time.
- *The gate names every mark:* `gate-selftest` shows the three refusals (a mark without a row, a row
  without a mark, a mark without a preset) turn `gate-licenses` red; the real run prints the list.

Steps, one commit each:

1. `docs(backlog)`: this record.
2. `refactor(webapp)`: `ProviderMark.svelte` draws only the marks with a preset (`GOOGLE`,
   `MICROSOFT`) and the tile; the comment names ADR-0069 §3 for why the others are gone.
   `signin.test.mjs` gains a `GOOGLE` provider and the test of § 4 (marks, tile, no foreign
   request).
3. `docs(licenses)`: the "Brand marks" table in `tools/licenses.md.tpl` with the Google and
   Microsoft rows, `THIRD-PARTY-LICENSES.md` regenerated with `make licenses`.
4. `ci(licenses)`: `scripts/check-brand-marks.sh`, called first by `gate-licenses`; three cases in
   `scripts/gate-selftest.sh`; `design-system.md` §12 and `ci-cd.md`'s `licences` row say it (D5).
5. `docs(usecases)`: UC-ID-09 `checked_by:` gains `apps/webapp/e2e/signin.test.mjs` and
   `scripts/check-brand-marks.sh`.
6. `fix(webapp)`: the Microsoft mark from `ms-symbollockup_mssymbol_19.svg`; its row names the file.
7. `fix(webapp)`: the Google mark from the published sign-in asset (D6); its row names the

8. `docs(usecases)`: UC-ID-09 back to `built`, check 4 proven.
