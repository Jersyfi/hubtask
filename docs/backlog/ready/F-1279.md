## 3. Decisions

- [x] D1 The door is the machine; the use case builds a `SYSTEM` actor named `machine` holding
  `admin:tenants` for the one workspace and hands it to `ResumeTenant` / `CancelTenantDeletion`
  unchanged — decided by: worker, following `RestoreOperator` (UC-INS-03: "whoever can reach the
  machine can run it"). No register check: in the case this exists for, nobody the register names
  can sign in. Rejected: a second implementation of the two edges (two places to keep the guards in
  step); a scope-less path inside the existing use cases (it would widen the API's use case).
- [x] D2 Open in every mode, not only single — decided by: worker. Whoever can run the binary can
  reach the database; refusing in multi mode protects nothing and leaves a multi-mode installation
  whose every operator sits in a suspended workspace with the same SQL-only way back. multi-tenancy.md
  §5 already says resume and cancel "stay open in every mode".
- [x] D3 The command is `hubtask workspace resume|cancel-deletion --workspace <short name>`, the
  flag spelled as `operator add`'s — decided by: worker; the issue named the verbs.
- [x] D4 A cancel that brings the workspace back suspended says so and names `resume`; the cancel
  does not resume by itself — decided by: multi-tenancy.md §5 (the status the request found it in),
  nobody regains access the operator did not choose.
- [x] D5 Not a retention safeguard change on the owner's list: it adds a door to the existing cancel,
  which removes nothing and returns access; no floor, hold or grace is weakened — decided by: worker,
  as F-1159's record D5 argued for its sweep.
- [x] D7 `RecoverWorkspace` has no `Descriptor()` and is not registered, as `RestoreOperator` is not:
  a registered use case is reachable by a route, and this one mints its own `admin:tenants` actor.
  Held by a unit test that the type offers no descriptor — decided by: worker (UC-INS-03 *Where it
  ends*, "no web route").
- [x] D6 Documents: identity.md §19 "The way back", multi-tenancy.md §5 (the paragraph on single
  mode), deployment.md §2.1, UC-INS-03 *Story* — decided by: worker; these are where `operator add`
  is documented.
