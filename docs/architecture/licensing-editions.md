# Licence and Edition Model

> The decision is [ADR-0080](../adr/ADR-0080-hubtask-is-apache-2-0.md). It supersedes
> [ADR-0059](../adr/ADR-0059-licensing-phases-and-licensing-start.md) and
> [ADR-0013](../adr/ADR-0013-licensing.md), which keep the reasoning behind the licence the
> project had before. This document is not legal advice.

---

## 1. The licence

Hubtask is licensed under the **Apache License, Version 2.0** — the whole repository, every
version, every image. Anyone may use, modify and redistribute it, commercially or not, under the
terms in [LICENSE](../../LICENSE). Every previously published state of the repository is made
available under Apache-2.0 as well.

| File | Purpose |
|---|---|
| [`LICENSE`](../../LICENSE) | The Apache License 2.0, verbatim |
| [`NOTICE`](../../NOTICE) | Copyright, the trademark line, the pointer to the third-party list |
| [`TRADEMARK.md`](../../TRADEMARK.md) | The name and the logo |
| [`THIRD-PARTY-LICENSES.md`](../../THIRD-PARTY-LICENSES.md) | What the binary links, generated by `make licenses` |
| SPDX headers | `SPDX-License-Identifier: Apache-2.0` in every hand-written source file; the header test in `test/architecture` holds them to it |

The SDKs (`sdk/go`, `sdk/python`, `sdk/typescript`), the contract (`api/`) and the connector
packages (`packages/n8n-nodes-hubtask`, `packages/zapier-app`) carry a `LICENSE` file of their own,
because each may be extracted into a repository or a registry of its own
([ADR-0057](../adr/ADR-0057-sdk-licence-and-extraction.md)). The licence is the same.

**The licence gate** (`make gate-licenses`) refuses GPL and AGPL dependencies, and the dependency
review in CI does the same for the JavaScript half: a copyleft dependency would change the terms
on which an Apache-2.0 binary may be passed on.

## 2. Contributions

Inbound = outbound: a contribution is licensed under Apache-2.0, as its section 5 says. There is
no Contributor License Agreement and no sign-off requirement
([CONTRIBUTING.md](../../CONTRIBUTING.md)).

## 3. The name

The licence covers the code, not the name: Apache-2.0 §6 grants no rights in a trademark.
[TRADEMARK.md](../../TRADEMARK.md) says what a fork may and may not call itself. Official images
come only from the project registry.

## 4. One edition

There is **one** code path and **one** image. No licence key, no commercial edition, no `ee/`
directory, no feature that is switched off anywhere. What differs between installations is
operational, never a matter of licence:

* `HUBTASK_TENANCY_MODE` chooses between one workspace and many.
* Quotas and the usage record (`usage_record`, the quota guard) let an operator of a shared
  installation bound what one workspace consumes. They are about operating an installation, not
  about licensing it.
* No telemetry without consent.

## 5. Funding

The work is funded by donations ([GitHub Sponsors](https://github.com/sponsors/Jersyfi),
[`.github/FUNDING.yml`](../../.github/FUNDING.yml)). A donation buys nothing in return — no
support, no priority, no feature. Hubtask is provided as is, as the licence says; the project makes
no maintenance commitment and may be archived. If it is, the code stays public under Apache-2.0
and anyone may continue it under another name.
