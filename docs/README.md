# Documentation

One place per kind of knowledge ([`AGENTS.md`](../AGENTS.md) § "Where knowledge lives"), and this
table names it. Write it there; elsewhere, link to it.

| Directory | What it holds | Who writes it |
|---|---|---|
| [`vision/`](./vision/README.md) | Why: principles, personas, the deployments D1–D7, non-goals | the owner |
| [`usecases/`](./usecases/README.md) | What must be true for a person — the yardstick for every change | the owner decides *Goal*, *How to check*, *Where it ends*; sessions keep *Today* and the state |
| [`architecture/`](./architecture/arc42.md) | The current rule of each concern, one subject document per concern; arc42 is the entry | the session that changes a rule, in the same pull request |
| [`design/`](./design/design-system.md) | The design system and the product's voice | the session that changes a rule, in the same pull request |
| [`adr/`](./adr/README.md) | Why and when each decision was taken — a log, not the rules | the session that records a decision, named to the owner |
| [`backlog/`](./backlog/README.md) | Running milestones with what they deliver, their tasks and decisions; readiness records; how work runs | sessions, at a cut and while a milestone runs |
| [`privacy/`](./privacy/data-catalog.md) | The data catalogue, technical and organisational measures, AI providers, the breach runbook | the session whose change touches personal data |
| [`audit/`](./audit/event-matrix.md) | The event matrix | generated by `make generate`, never by hand |
| [`evidence/`](./evidence/README.md) | Runs no pipeline can make, and the current coverage report | the session that made the run |
| [`archive/`](./archive/README.md) | Closed milestones, old run records, superseded drafts — history only | moved there when done; only its links are kept working |
| [`roadmap.md`](./roadmap.md) | What is still ahead on the way to `1.0.0` | sessions, at a cut or a release |

Traps that have no home in code or a subject document are in
[`architecture/known-traps.md`](./architecture/known-traps.md). A question for the owner is an issue
labelled `decision`; something found outside the task is an issue labelled `finding`.
