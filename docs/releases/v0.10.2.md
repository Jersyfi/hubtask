## Summary

v0.10.2 makes the installed apps sign in again and finishes a database change that v0.10.0 began.

* **The Android app opens the sign-in.** In v0.10.1 *Sign in* opened no browser on Android, and the
  update notice's download did not open either. Both open in the system browser now.
* **An installed app signs in to a server built from `main`.** The app read such a server's
  version as older than itself and stopped at the address field. A server version without a
  release part now counts as a development build, newer than every release.
* **The web app's layout and navigation are tidied** after the owner's walk through it: spacing
  and card surfaces, the administration and installation columns, the settings pages, and the
  cards of *Today*. Posts are a module of their own.
* **The slim entry's second contract step.** Migration 0445 drops eight columns of the entry, the
  trigger that mirrored them and the indexes on them. No binary has named these columns since
  v0.10.1, and the schema's compatibility floor is now migration 0442, the first of v0.10.1.

**Upgrading.** Upgrade to v0.10.1 first where an installation runs an older version, then to
v0.10.2: the migration removes columns that binaries before v0.10.1 still read.
